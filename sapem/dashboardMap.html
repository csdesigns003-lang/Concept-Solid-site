Add Receiving Hub

Enter the hardware ID printed on your Raspberry Pi hub, then give it a friendly name.

Add Sensor Node

Enter the 4-digit serial number on your sensor, then give it a name.

New sensors won't show any readings right away -- data appears once the sensor reports in next, which can take a few minutes.

Assign Sensor to Hub

A sensor can appear on one hub, multiple hubs, or none (unassigned).

"Assign" adds this hub without touching any hub the sensor is already on. "Move" makes this the sensor's only hub.

Remove Hub?

The hub will be removed from the dashboard.
